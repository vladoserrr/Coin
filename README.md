# COIN — игровой клуб

Премиальное адаптивное веб-казино с 14 игровыми режимами, виртуальными кредитами и таблицей лидеров.

## Возможности
- 14 режимов: Кости, Монетка, Рулетка, Мины, Слоты, Плинко, Колесо, Выше-ниже, Блэкджек, Баккара, Кено, Краш, Лимбо и Башни.
- Виртуальный баланс без пополнений и выводов.
- Профиль игрока с игровым именем.
- Общая таблица лидеров через серверный API.
- Сезонные виртуальные награды за первые три места.
- Адаптивный интерфейс для телефонов и компьютеров.

## Запуск
Требуется Node.js 18 или новее.

```bash
npm start
```

Сервер слушает `PORT` (по умолчанию 8080).

## Railway
Подключите репозиторий к Railway как Node.js-сервис. Команда запуска: `npm start`. После первого успешного деплоя создайте Public Domain в настройках сервиса.

Для сохранения таблицы лидеров между перезапусками подключите Railway Volume и направьте постоянный путь хранения в директорию проекта, содержащую `data/players.json`, либо замените файловое хранилище на внешнюю базу данных. Без постоянного диска локальный JSON-файл может сбрасываться при пересоздании контейнера.

## Важно
Все кредиты и награды виртуальные. В проекте нет платёжных интеграций, пополнений, вывода средств или реальных денежных выплат. Рейтинг MVP хранит очки на сервере; для публичного запуска рекомендуется добавить авторизацию Telegram и защиту игровых результатов от подмены клиентом.
