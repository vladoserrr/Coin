# Пончик — светлый кликер

Лёгкий Telegram Mini App / веб-кликер с энергией, медленной экономикой, улучшениями, рейтингом по балансу и реферальной наградой.

## Запуск
- Node.js 18+
- `npm start`
- Railway: подключить репозиторий и создать Public Domain.
- Для Telegram добавить `TELEGRAM_BOT_TOKEN` в Variables и открыть Mini App через бота.

## Экономика
- Старт: 0 пончиков, 100 энергии.
- Один тап: +1 пончик, −1 энергия, +1 XP.
- Энергия: +1 каждые 30 секунд.
- Улучшения дорожают на 72% за каждый уровень.
- Реферальная награда: +1 пончик пригласившему, когда приглашённый достигает 3 уровня.
- Топ сортируется строго по балансу.

Данные игроков хранятся в `data/players.json`. Для Railway подключите постоянный Volume в `/app/data`.
