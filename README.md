# COIN — игровой клуб

Адаптивная игровая платформа с 14 режимами, виртуальными кредитами, Telegram-профилями и сезонным рейтингом.

## Возможности
- 14 игровых режимов с отдельными анимациями раундов.
- MD5-идентификатор результата каждого завершённого раунда.
- Виртуальный баланс без пополнений и вывода реальных денег.
- Telegram Web App авторизация с проверкой подписи initData на сервере.
- Таблица лидеров с Telegram username и аватарками.
- Внутренние переводы виртуальных CR по Telegram username.
- Вкладка «Ещё» и закрытая админ-панель для @vladubrat7.
- Telegram-рассылка самому себе или всем зарегистрированным участникам.
- Сезонные виртуальные награды первым трём местам.

## Запуск
Требуется Node.js 18 или новее.

```bash
npm start
```

Сервер слушает `PORT` (по умолчанию 8080).

## Настройка Telegram в Railway
В Variables сервиса добавьте секретную переменную:

- `TELEGRAM_BOT_TOKEN` — токен бота, который запускает Mini App.

Также поддерживаются имена `BOT_TOKEN` и `TELEGRAM_TOKEN`, если они уже используются в проекте. Токен хранится только в переменных Railway и не должен попадать в клиентский код или GitHub.

Mini App должен открываться через Telegram Web App, чтобы сервер мог проверить подписанные Telegram-данные пользователя. Username и аватар загружаются из Telegram. Для переводов получатель должен хотя бы один раз открыть Coin через Telegram, чтобы появиться в базе игроков.

Для рассылки бот должен иметь возможность писать пользователю: пользователь должен ранее открыть чат с ботом и не блокировать его. Кнопка «Отправить всем» отправляет сообщения всем зарегистрированным Telegram-игрокам, у которых доступна доставка.

Админ-доступ проверяется сервером по подписанному Telegram initData и username `vladubrat7`. Скрытие кнопки в интерфейсе не является единственной защитой.

## Railway
Подключите репозиторий к Railway как Node.js-сервис. Команда запуска: `npm start`. После успешного деплоя создайте Public Domain в настройках сервиса.

Для сохранения таблицы лидеров и балансов между пересозданиями контейнера подключите Railway Volume к `/app/data`. Без постоянного диска локальный JSON-файл может сбрасываться при пересоздании контейнера.

## Важно
Все кредиты и награды виртуальные. В проекте нет платёжных интеграций, пополнений, вывода средств или реальных денежных выплат. MD5 отображается как идентификатор раунда, а не как самостоятельное доказательство честности результата. Для публичного запуска также рекомендуется перенести расчёт исходов и изменение балансов полностью на сервер.
