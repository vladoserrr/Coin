API для проектов

Подключай баланс пончиков к своим сайтам, ботам и приложениям.

Твои API-ключи

Создавай отдельный ключ для каждого проекта. Секрет показывается только один раз.

Загружаем ключи…

Документация API

Базовый адрес:

1. Проверить баланс

GET /api/v1/balance?telegram_id=123456789
Authorization: Bearer pn_live_ВАШ_КЛЮЧ

Без telegram_id вернётся твой баланс.
С telegram_id — баланс игрока, который запускал бота Пончик.

2. Начислить или списать пончики

POST /api/v1/transactions
Authorization: Bearer pn_live_ВАШ_КЛЮЧ
Content-Type: application/json

{
  "telegram_id": "123456789",
  "type": "credit",
  "amount": 50,
  "reference": "order-2026-0001",
  "description": "Награда за заказ"
}

Для списания укажи "type": "debit". Сумма — целое число от 1 до 1 000 000. Каждый reference должен быть уникальным для проекта: повтор запроса с тем же reference не спишет и не начислит пончики второй раз.

Важно: ключ принадлежит твоему проекту. Без telegram_id операция работает с твоим балансом; с telegram_id — с балансом указанного игрока, который уже зарегистрирован в боте Пончик. Это позволяет использовать пончики как валюту в стороннем проекте. Доступ к балансам игроков — доверенная привилегия: храни ключ только на сервере, не вставляй его в публичный JavaScript или мобильное приложение. При утечке немедленно отзови ключ.
